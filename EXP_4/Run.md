## How to Run

1. Open the EXP_4 folder in VS Code.
2. Open the terminal in that folder.
3. Install dependencies if required.
4. Run the Node.js server using the correct entry filename.
5. Test the GET and POST routes in your browser or API client.

Example command, if your entry file is `server.js`:

```bash
node server.js
```
